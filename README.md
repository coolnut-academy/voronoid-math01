## 📌 1. ชื่อผลงาน

**"เว็บแอปพลิเคชันสำหรับหาตำแหน่งที่เหมาะสมในการติดตั้งเสาเตือนภัยอุทกภัยอัจฉริยะ โดยใช้ Voronoi Diagram"**

ระบบ Web Application ที่ช่วยวิเคราะห์และคำนวณตำแหน่งที่เหมาะสมที่สุดในการติดตั้ง **Sensor Gateway (เสาเตือนภัยอุทกภัย)** โดยคำนึงถึงการกระจายตัวของชุมชน เพื่อให้ทุกหมู่บ้านได้รับการแจ้งเตือนภัยอย่างทั่วถึงและรวดเร็วที่สุด

## 💡 2. แรงบันดาลใจ / ที่มาของโครงการ

> *"เมื่อน้ำมา…ทุกวินาทีคือชีวิต"*

จังหวัดแม่ฮ่องสอนเป็นพื้นที่ที่เผชิญกับ **ปัญหาอุทกภัยซ้ำซาก** เนื่องจากสภาพภูมิประเทศเป็นหุบเขาสลับซับซ้อน ล้อมรอบด้วยแนวเทือกเขา ทำให้เมื่อเกิดฝนตกหนักหรือน้ำป่าไหลหลาก ชุมชนในพื้นที่ลุ่มจะได้รับผลกระทบอย่างรุนแรง ปัญหาสำคัญที่พบคือ:

- 🏔️ **ภูมิประเทศเป็นหุบเขา** — น้ำไหลรวมตัวเร็วและแรง ทำให้ชุมชนในที่ลุ่มมีความเสี่ยงสูง
- ⏰ **การแจ้งเตือนล่าช้า** — ในหลายพื้นที่ยังอาศัยการแจ้งข่าวแบบปากต่อปาก ทำให้ประชาชนอพยพไม่ทัน
- 📍 **ขาดข้อมูลเชิงพื้นที่ในการวางแผน** — การเลือกจุดติดตั้งเสาเตือนภัยยังไม่ได้ใช้หลักการทางคณิตศาสตร์หรือข้อมูลเชิงพื้นที่อย่างเป็นระบบ

จากปัญหาข้างต้น ทีมผู้พัฒนาซึ่งเป็นนักเรียนระดับมัธยมศึกษาของโรงเรียนห้องสอนศึกษา ในพระอุปถัมภ์ฯ จึงได้นำ **ทฤษฎี Voronoi Diagram** ร่วมกับ **อัลกอริทึม K-Means Clustering** มาประยุกต์ใช้ในการคำนวณตำแหน่งที่เหมาะสมที่สุด เพื่อให้การกระจายจุดเตือนภัยครอบคลุมทุกชุมชนอย่างมีประสิทธิภาพสูงสุด โดยใช้เกณฑ์ **Minimax** (ลดระยะทางสูงสุดที่ชุมชนไกลที่สุดต้องเดินทาง) และ **Least Squares** (ลดผลรวมระยะทางรวม)

## 🎯 3. ประโยชน์ที่ได้รับ

### 🔬 ด้านวิชาการ
- ✅ เป็นสื่อการเรียนรู้ที่แสดงให้เห็นการประยุกต์ใช้ **คณิตศาสตร์ในชีวิตจริง** ตั้งแต่ Voronoi Diagram, Haversine Formula ไปจนถึง K-Means Clustering
- ✅ ส่งเสริมทักษะ **Computational Thinking** ให้กับนักเรียนผู้พัฒนา

### 🛡️ ด้านการป้องกันและบรรเทาสาธารณภัย
- ✅ ช่วยให้หน่วยงานภาครัฐสามารถ **วางแผนติดตั้งเสาเตือนภัยได้อย่างเป็นระบบ** บนพื้นฐานข้อมูลเชิงพื้นที่
- ✅ ลด **ระยะทางสูงสุด** (Max Distance) ระหว่างชุมชนกับจุดเตือนภัย ทำให้ทุกชุมชนสามารถรับสัญญาณเตือนได้อย่างทั่วถึง
- ✅ รองรับการ **ปรับเปลี่ยนตำแหน่งแบบ Real-time** (ลาก Marker) เพื่อจำลองสถานการณ์จริงก่อนลงพื้นที่ติดตั้ง

### 💰 ด้านงบประมาณ
- ✅ ช่วยวิเคราะห์จำนวน Sensor Gateway ที่เพียงพอและเหมาะสม ลดการใช้งบประมาณโดยไม่จำเป็น
- ✅ เป็นเครื่องมือ **ฟรี ไม่มีค่าใช้จ่าย** ทำงานบนเว็บเบราว์เซอร์ได้ทันที ไม่ต้องติดตั้งซอฟต์แวร์เพิ่มเติม

### 🌐 ด้านการเข้าถึง
- ✅ ใช้งานง่าย มี UI/UX ที่เป็นมิตร รองรับทั้ง **Desktop และ Mobile**
- ✅ รองรับการนำเข้าข้อมูลหมู่บ้านผ่าน **ไฟล์ CSV** เพื่อความสะดวกและรวดเร็ว

## 👥 4. บุคคล หน่วยงาน หรือผู้ที่ได้รับประโยชน์จากนวัตกรรมนี้

| กลุ่มเป้าหมาย | รายละเอียดประโยชน์ที่ได้รับ |
|:---|:---|
| 🏛️ **องค์กรปกครองส่วนท้องถิ่น (อปท.)** | ใช้เป็นเครื่องมือในการวางแผนและตัดสินใจเลือกจุดติดตั้งเสาเตือนภัยอย่างมีหลักการทางวิทยาศาสตร์ |
| 🛡️ **สำนักงานป้องกันและบรรเทาสาธารณภัย (ปภ.)** | สนับสนุนการวางแผนป้องกันอุทกภัยเชิงรุก ลดความสูญเสียจากภัยพิบัติ |
| 👨‍👩‍👧‍👦 **ประชาชนในพื้นที่เสี่ยงอุทกภัย** | ได้รับการแจ้งเตือนภัยที่ทั่วถึงและรวดเร็วยิ่งขึ้น เพิ่มโอกาสในการอพยพอย่างปลอดภัย |
| 🎓 **นักเรียน นักศึกษา นักวิจัย** | เป็นแหล่งเรียนรู้การประยุกต์ใช้คณิตศาสตร์ (Voronoi, K-Means, Haversine) กับปัญหาจริงในชุมชน |
| 🗺️ **หน่วยงานด้านภูมิสารสนเทศ** | ใช้เป็นต้นแบบในการพัฒนาเครื่องมือวิเคราะห์เชิงพื้นที่สำหรับจุดบริการสาธารณะอื่น ๆ |

## 🛠️ 5. เทคโนโลยีที่ใช้ในผลงาน

### 🌐 Web Application
ผลงานนี้พัฒนาในรูปแบบ **Progressive Web Application (Web App)** ที่ทำงานได้บนเบราว์เซอร์ทุกแพลตฟอร์ม ไม่ต้องติดตั้งแอปพลิเคชันเพิ่มเติม

### 📚 เทคโนโลยีหลักที่ใช้

| เทคโนโลยี | วัตถุประสงค์ | รายละเอียด |
|:---|:---|:---|
| **HTML5 + JavaScript** | โครงสร้างและลอจิกหลัก | พัฒนาระบบ Single-Page Application |
| **Tailwind CSS** | ออกแบบ UI/UX | สร้างส่วนติดต่อผู้ใช้ที่สวยงาม ตอบสนองทุกขนาดหน้าจอ |
| **MapLibre GL JS** | แสดงแผนที่ 2D/3D | แสดงแผนที่ดาวเทียมแบบ Interactive พร้อมภูมิประเทศ 3D (Terrain) |
| **D3.js** | คำนวณ Voronoi Diagram | สร้าง Delaunay Triangulation และ Voronoi Tessellation |
| **Chart.js** | แสดงผลกราฟ | รองรับการแสดงผลข้อมูลเชิงสถิติ |
| **MapTiler API** | แผนที่พื้นหลัง | ให้บริการ Satellite Imagery และ Terrain DEM |

### 🧮 อัลกอริทึมและหลักการทางคณิตศาสตร์

| อัลกอริทึม / สูตร | บทบาทในระบบ |
|:---|:---|
| **K-Means Clustering** | จัดกลุ่มหมู่บ้านและหาจุดศูนย์กลาง (Centroid) ที่เหมาะสมสำหรับติดตั้ง Sensor Gateway |
| **Voronoi Diagram** | แบ่งพื้นที่ครอบคลุมของแต่ละ Sensor Gateway แสดงให้เห็นขอบเขตการให้บริการอย่างชัดเจน |
| **Haversine Formula** | คำนวณระยะทางจริงบนพื้นผิวโลก (Great-circle Distance) ระหว่างสองพิกัด |
| **Minimax Optimization** | หาตำแหน่งที่ทำให้ระยะทางสูงสุด (จากหมู่บ้านที่ไกลที่สุด) มีค่าน้อยที่สุด |
| **Least Squares** | ลดผลรวมของระยะทางกำลังสองจากทุกหมู่บ้านถึง Sensor ที่ใกล้ที่สุด |
